## Описание
Голосовой и текстовый AI-ассистент для создания событий в календаре. Тестовое задание хакатона GorkyCode.

## Перед запуском

### Установка зависимостей
```shell
npm i
```

### Переменные окружения
Все переменные окружения прописывать в `.env`:
- `NUXT_DEV_PORT`?: номер порта в режиме разработки
- `NUXT_PUBLIC_SITE_URL`: URL сайта
- `NUXT_PUBLIC_API_BASE`: URL к API

## Разработка

```shell
npm run dev
```

## Сборка

```shell
npm run generate
```
